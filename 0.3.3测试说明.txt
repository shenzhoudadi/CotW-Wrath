0.3.3：ModMenu 状态页接入测试

本版目的
新增一个真正可见的菜单入口，用来查看版本与本次启动的模块注册结果、向日志写入诊断信息。三个专长及拳斗士列表接入规则不变；菜单不是角色已选专长列表。所有新增游戏内文字继续为英文。本版没有专长启停开关。

依赖与安装
1. 完全退出游戏，按 README 升级本实验包，保持唯一启用副本。
2. 菜单需要另外安装并启用 CasDragon 维护的 ModMenu；本次对照版本为 2.0.14：
   https://github.com/CasDragon/ModMenu/releases/tag/2.0.14
   该发布包 Info.json 声明 Unity Mod Manager 最低 0.27.11，请用 UMM 安装 ModMenu。ModMenu 不包含在本实验包里。
3. 本实验包仍通过 Owlcat 官方加载器安装和启用，不要将它作为 UMM 模组安装，也不要把 ModMenu.dll 放进本包 Assemblies。
4. 按 ModMenu 上游说明使用键盘鼠标测试；它不支持手柄界面。

主测试：不需要打怪
1. 启动到主菜单，打开设置（Options）→ Mods / 模组，在下拉列表选择 Call of the Wild - Wrath Prototype。
2. 页面应显示 Version 0.3.3。三个专长各有一行，正常应为 Registered。
3. 如果未装 BrawlerClassWrath，Brawler combat feat integration 应显示 Not detected，这不是错误。装有它且满足接入条件时应为 Registered；Failed 表示注册失败，需查看对应启动日志。
4. 悬停各行，右侧应显示英文说明。点击 Write log，应在游戏日志中出现 CotW Wrath 0.3.3 及四个模块状态；点击任一状态按钮，应记录对应模块说明。点击按钮不改变角色、专长、资源或游戏规则。
5. 关闭并重开设置三次，下拉列表中本模组仍只有一项。中文/英文切换后重新打开设置，标题、状态及说明均应继续显示英文，不能出现空白或 unknown key。
6. 读取原测试档，核对已有专长仍在；简单复测已验证的攻击罚值。退出游戏重进后，菜单与原测试档应仍正常。

可选边界检查
仅禁用 ModMenu（保留本实验包），完整重启：专长仍应正常，菜单不出现；日志会说明 ModMenu not loaded。重新启用 ModMenu 并重启，菜单应恢复。不要为了此项禁用其他依赖 ModMenu 的模组组合；可使用独立测试环境。

反馈
请提供本页截图、ModMenu 与 UMM 版本，说明是否装有 BrawlerClassWrath，以及上面实际完成的步骤。
日志目录：%USERPROFILE%\AppData\LocalLow\Owlcat Games\Pathfinder Wrath Of The Righteous
优先 GameLogFull.txt；查找 Registered: ModMenu status page、ModMenu integration failed 或 ModMenu not loaded。取日志方法详见《测试者必读.txt》。

本机构建验证边界
已检查 ModMenu 2.0.14 真实 DLL 的所用公开接口签名；菜单适配器用模拟接口验证缺失、晚到、失败隔离、重复注册、按钮诊断和语言包重建。未启动 Unity，尚未实际观察菜单绘制及与 ModMenu 的完整游戏内共存。ModMenu 自身的 Harmony/UMM 要求独立于本包，不能把本包的旧 Harmony 测试结论推广给 ModMenu。
