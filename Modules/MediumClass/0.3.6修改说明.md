# Medium Class 0.3.6 启动修复

0.3.5收到与CotW0.6.0同时安装时打开游戏卡加载的反馈。日志首个异常位于通灵入口的超魔文字补丁；原生UIUtilityTexts静态初始化在BlueprintRoot尚不存在时失败，之后TTT读取法术说明再次抛出同一异常。

0.3.6把GetMetamagicName/GetMetamagicList补丁推迟到AfterBlueprintCacheInit，在调用前核对UI依赖，按owner避免重复安装。入口保留其他原补丁和事件订阅；不替换Harmony，不改变旧GUID、TypeId、法术表、资源与0.3.5统帅/能力清理修复。需要同步替换CotW为0.6.1，并完全退出后重启。

新启动时机检查及三版Harmony/两种顺序通过；旧包失败经独立夹具复现。这里只是带明确替代的托管检查，非游戏启动验收。具体范围、全部校验和本轮原套件复核见交付校验记录；历史0.3.5/0.3.4检查保留版本归属。

测试者先确认主菜单能加载，然后按《测试指引》复测异能施法和两项通灵缺陷。另有WrathPatches 1.19.1的CodeMatcher/Harmony版本不符错误，独立于本次修复；若仍卡加载，保存日志并临时关闭它以隔离。
