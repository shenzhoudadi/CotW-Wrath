# MediumClass 0.3.4 测试指引

本版处理三项反馈：**通灵者兼职按总等级发放进度**、**灵力涌动共用一次投骰并显示明细**、**恶咒最多同时两种**。离线验证（真实生产源码 + 明确的 API 模型 + 原生程序集/蓝图核对）不能替代实机验证；下面所有“预期”都是待你确认的验收目标，**目前没有任何一项由实机确认**。

升级前请备份旧存档，测试时另存新档，尤其是“兼职通灵者”的 0.3.3 存档和带多个恶咒能量的 0.3.3 存档。没有相应等级/能力的项目可跳过，并注明“未测”。

> 本包是 Windows StageMod 重打并复核后的 0.3.4。新增迁移回归已通过，但以下游戏内项目仍待测试者验证。

## 一、安装与启动

1. 退出游戏，按原安装方式更新为 `MediumClass-0.3.4-UMM.zip`（只含 `Info.json`、`MediumClass.dll`、`mediumclass_assets`）。
2. 启动游戏，确认 UMM 中 Medium Class 显示 **0.3.4**，无红色报错。
3. 加载测试存档，看角色界面和能力栏，再打一场战斗。若加载失败或模组异常，先保留旧档并提供 UMM 日志。日志里以 `Recovery:`、`Death Curse:` 开头的行是本版存档修复的记录，请一并提供。

## 二、通灵者兼职：按职业等级授予（新增，重点）

预期的规则：能力按**通灵者职业等级**授予；角色总等级、其他职业等级不影响。

### 2.1 新建角色
1. **纯通灵者**：新建 1 级通灵者。**预期**：英灵同调、英灵之力、灵力涌动、降灵、共鸣、英灵施法（隐藏施法/共鸣部件）、通灵者擅长（熟练项）等一级能力齐全；升到 2 级得到降灵会，之后按下面第 4 项的等级增加。
2. **骑将 1 → 通灵者 1**（总等级 2）。**预期**：得到完整的通灵者 1 级能力（与第 1 项相同），**没有**降灵会；升级预览里显示的是通灵者 1 级条目。
3. **其他职业 7 级 → 通灵者 1**（总等级 8）。**预期**：同样是通灵者 1 级完整能力，没有 8 级/9 级/10 级条目。
4. 继续混职升级，逐级记录：
   - 再升通灵者到 2：降灵会；到 4：英灵同调 +1；到 6：英灵之力 +1；到 9：慰灵之术；到 10：灵力涌动升级（1d8）；到 20：终极能力。
   - **只升其他职业时**，通灵者能力不应变化；通灵者升级预览也不应显示总等级对应的条目。
   - 没有重复叠加（同一能力不应出现两份）。
5. **缚灵者**（变体）：重复第 2、3 项。**预期**：1 级有“永不安宁”；额外专长选择出现在**缚灵者 2/3/5/7/9/11 级**（不是总等级）；变体移除/替换的能力保持原有行为。
6. **绝境巡行者**（血怒者变体）：本次没有改动其进度规则。**预期**：仍按血怒者等级获得涌动/同调等，不受“通灵者职业等级”影响；请确认没有变化。

### 2.2 0.3.3 旧档（受影响的兼职角色）
读入 0.3.3 时创建的兼职存档（例如骑将 1 + 通灵者 1）的**备份副本**：
1. 载入后查看角色能力。**预期**：通灵者 1 级能力齐全；早先得到的“降灵会”等超前能力被移除；UMM 日志出现 `Recovery: granted missing …` / `removed …` 行。
2. 另存、退出到主菜单、重新读取。**预期**：不再发生变化（迁移幂等），日志没有新的 `Recovery: granted missing …` / `removed …` 行。选择项或无法核实来源的说明可以重复出现，它们不是新增迁移。
3. 再升一级通灵者（例如到 2）。**预期**：得到降灵会一次，不重复。再升其他职业：通灵者能力不变。
4. **不应受影响**：共鸣当前值、每日次数、已准备法术、法术位（本版不补满也不清零）。请记录补齐前后这些数值；**补齐新增能力时游戏怎样初始化其资源属于原生行为，尚未验证**。
5. **缚灵者旧档**：额外专长选择**不会自动增删**（日志有 `feature selection(s)` 提示），已选的额外专长在读档后必须**全部保留**（每次读档都检查一次，新旧存档都要）。请记录多得/少得的专长；需要严格规则可对该职业等级重训重新选择。
6. 条目原本正确的存档（例如纯通灵者、或已正确升级的）：**不应有任何变化**，也不应有新增/删除能力的 `Recovery:` 行；缚灵者选择项提示可以保留。

## 三、灵力涌动：一次效果一个骰点（更新，重点）

1. 单人降灵（例如一个英灵），使用灵力奔涌（游戏内能力名；日志行以“灵力涌动”开头），展开各属性修正。**预期**：每个受益属性的涌动部分**数值相同**（同一个骰点），并且战斗日志有一行：
   `<接收者> 灵力涌动：1d6 = 4；<属性、属性…>：骰点 4 = +4；专注：…`（骰型随等级 1d6/1d8/1d10）。
2. 同时降灵统帅：`攻击、…：骰点 4 + A 的统帅同调 2 + 专攻 1 = +7`。**预期**：统帅相关属性 = 骰点 + 授予者的统帅同调 + 授予者的专攻；不含统帅的属性只有骰点。请在角色面板展开修正来源，逐项核对日志上每个“= +N”。
3. **统帅之令**对盟友 B：B 的日志写 B 的名字，附加项取自 A（授予者），即使 B 自己也是通灵者/有统帅专攻，也不替换 A 的数值；对两名盟友分别施放，各有各的骰点。
4. **坚毅灵魂**（2d8）：日志显示两个骰点，如 `2d8 = 3 + 6 = 9`；各属性共用这一组 3 和 6。**绝境巡行者**：d6。**传奇统帅**：固定 1d6，没有同调项，日志只有骰点。
5. **专注检定**：涌动/统帅之令的专注部分应与日志“专注：…”里的加值一致，重复查询（多次专注检定）数值不变。
6. **存读档**：涌动生效期间保存、读档（也试试切换地图）。**预期**：数值不变、日志**不**重复出现、不重新投骰。**旧档**：0.3.3 存档里仍在持续的涌动，读档后可能重投一次（≤5 轮），请另存为 0.3.4 新档，再退出到主菜单重读两次；转换后不应继续变化。若每次读同一份未转换的 0.3.3 原档，仍可能触发首次恢复投骰。
7. 效果结束后修正应清除；**再次施放**应重新投骰（结果可以不同）；短时间内重复施放只保留一份效果。
8. 观察日志失败是否影响机制：日志缺失时，分别记录“日志缺失”“实际修正是否正确”“是否伴随异常”。

## 四、阿德里尔的恶咒：最多同时两种（更新，重点）

请使用已经能获得阿德里尔**至高英灵之力**的角色。

1. 降灵阿德里尔，检查恶咒下有负能量、火焰、寒冷、电击、酸蚀五个开关。
2. **上限**：开启任意两种（含负能量）。**预期**：第三种不能开启——按钮变灰并给出“最多同时开启两种”提示；若强行点击/连点，也不会开出第三种，并弹出“请先关闭其中一种”的警告。**不应**自动替换某一种。
3. 已开两种时，点击其中一种再次使用，应能关闭；关闭后可以开启另一种。逐个试 5 选 2 的组合，至少覆盖含负能量与不含负能量的组合。
4. 伤害：命中自己的挑战目标，展开伤害记录。**预期**：每种已开能量各 1d6（最多两份）；没有开启任何能量、目标不是自己的挑战对象、没有降灵阿德里尔时不应有恶咒伤害；结束降灵后所有能量关闭，再次降灵时全部关闭；休息后再检查一次。
5. 保存/读档：开启两种后保存、退出到主菜单、读档，再攻击。**预期**：两种保持，没有多出第三种；读档后仍然不能开第三种。
6. **旧档专项（0.3.3 开了 3–5 种）**：载入备份副本。**预期**：读档后只剩两种——**最早开启的两种**（buff 列表顺序）；其余被关闭；UMM 日志有 `Death Curse: n energy toggle(s) beyond the limit…`；另存再读不会“复活”第三种。请记录旧档原来开了哪几种、实际留下哪两种、是否与“最早开启”一致。
7. 0.3.0/0.3.1 的旧成对恶咒存档：仍应能读档，旧成对状态被清理，新开关可用（0.3.3 已有的行为，属回归项）。
8. 有另一名带挑战的角色时，分别检查各自的挑战目标，存读档后不要串给对方。

## 五、其他回归抽查（沿用 0.3.3）

- 英灵专攻选取：一行入口，可选六个职阶，已选不能重复；存读档保留；非通灵者不能选取。
- 缚灵者的“永不安宁”卡片；勇士/守护者次级能力、统帅高等能力的名称说明无空白。
- 英灵共鸣镜像：A +2、B +4、C 无自身同调 → C +4；C 自身 +2/+4 时取自身与外部最高；结束顺序、存读档、切换地图后数值一致。
- 有降灵和无降灵时的一环“剩余/最大次数”存读档两次不应变化。
- 瞬袭与加速术同时生效时额外攻击正确叠加；多重降灵数值惩罚按正式降灵数量分摊；诡术师技能级数专项（记录角色等级、技能点、展开的技能修正）。
