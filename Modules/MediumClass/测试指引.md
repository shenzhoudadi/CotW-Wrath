# MediumClass 0.3.8 异能施法测试指引

本版以 Windows 复核后的 0.3.4 为基线，将通灵者主法术书接入思想/情感异能施法。独立检查已通过，尚未启动游戏；以下都是待验收的预期。

安装包为 `MediumClass-0.3.8-UMM.zip`，继续用原来的 UMM 安装方式。完全退出游戏后更新；本版仍依赖原有 TabletopTweaks-Core 与 ModMenu，不新增 CotW 依赖。不要同时安装两份 MediumClass。旧档先留备份，测试另存。

1. 启动与升级：UMM 显示 0.3.8，无红色报错。纯通灵者1级、其他职业7级再加通灵者1级、缚灵者1级应得到 `Psychic Spellcasting` 和 `Center Self (Medium)`。其他职业升级不能提前推进通灵者。绝境巡行者仍使用原血怒者法术书。
2. 旧档补授：读取原来正常的0.3.4通灵者档，应补齐上述凝神能力，不改变已有其他能力层数。再保存、退出、重读两次，应不再重复补授。记录共鸣、已消耗次数、已准备法术和法术位是否保留；代理没有验证真实存档流程。
3. 准备与扣次：低级分别降灵大法师、祭司，准备一个0环和1环法术，再从通灵者主法术书施放。仅主书能施法、准备书不能直接施法；共享次数按原0.3.4规则消耗。先施放一次再追加第二施法英灵，不应补满；结束降灵和再次休息应保持原流程。13/20级抽查最高可用法术环数。
4. 思想成分：在回合制中，用会触发防御施法/受伤专注检定的场景比较。未凝神时，专注加值有额外 -10；用移动动作 `Center Self (Medium)` 后同一轮恢复正常，既有英灵同调/涌动等加值保留。下一轮凝神到期恢复 -10。凝神不取消情感限制；也不提高兼职法师等其他法术书的专注。
5. 情感成分：施加 Shaken/Fear 或有 Negative Emotion 描述符的负面效果（百宝袋可在测试档添加原生效果），主书法术应不能施放。效果移除或被压制后恢复。英雄气概一类有益情感不阻止施法。没有情感描述符的其他减益不凭名称推定会阻止。
6. Logical Spell：正常升级选取 `Metamagic (Logical Spell — Medium)`（需通灵者1级；百宝袋可辅助测试）。对主书法术创建 Logical 超魔版本，应提高1环，在上述情感效果下仍可施放，并消耗提高后的法术位。Logical 仍保留思想 -10，需凝神消除；不能突破其他禁止施法。七环配方不应作为通灵者法术开放。
7. 无语言/姿势成分：穿护甲、持盾时，主书异能法术不产生奥术失败率；变形后仍能施放可用的主书法术。支持的原生沉默效果是 ThrowingAxeOfSilenceBuff 与 SlaughteringSilenceBuff。只有沉默可豁免；同时有狂暴、Transformation 或其他禁法来源时仍不能施法。其他模组的沉默尚未审计；出现问题提供其来源或蓝图GUID。麻痹期间的动作执行仍沿用引擎，未声称实现完整桌面动作规则。
8. 兼职与物品：普通法师/牧师/血怒者等法术书、卷轴/魔杖、英灵类法术能力保持原规则，不受通灵者思想/情感新限制。主书中的英灵临时法术和超魔副本适用同一异能规则；结束降灵后原有临时法术和旧快捷栏仍应撤销。
9. 与 CotW 0.6.2 共存：分别新建通灵者和 Psychic，检查两者各自 -10、各自凝神、Logical 名称只出现一次。两份 Logical 专长使用同一标记，选取两份没有额外效果，混职角色只需选一份。单独 MediumClass 也应有完整的本版施法机制。
10. 统帅同调修复：选通灵者4级（同调+2），先记录攻击、三项豁免、知识秘法、Persuasion和Use Magic Device，再单独降灵统帅，暂不使用涌动或激励召唤。仅两项魅力技能增加同调；攻击、豁免和其他技能不凭统帅被动同调增加。用统帅指令后攻击/豁免/技能与专注仍得到该次涌动，骰值和日志一致；激励召唤本来的表现攻击加值仍有效。传奇统帅仍只给予1d6。多重降灵同时有勇士时，勇士的攻击同调仍有效。若有神话镜像，盟友也只能镜像统帅的魅力技能。旧档进入后及保存退出重读抽查同一组数值。
11. 降灵能力清理（重点）：用11级以上通灵者降灵勇士，确认能力栏有 Fleet Charge（狂飙猛进）和瞬袭，完整休息后这些降灵新增主动能力应消失；继续抽查大法师、祭司、统帅、守护者与诡术师。主动能力及开关能力都检查，变体折叠栏也检查。多重降灵与20级星界信标角色结束降灵后，所有新增英灵能力一起撤销。凝神、永久职业等级层数及其他职业/物品能力保留。以旧0.3.4残留档升级：若已无降灵标记，读档后旧残留应清除；有正在降灵的标记则保留，待正常结束后移除。每种情况保存、退出、重读，确认能力不再返回。记录结束方式（完整休息/移除主降灵效果）、残留按钮是否可点击，展开变体并关闭重开能力栏。
12. 0.3.4回归：兼职进度仍按通灵者职业等级；灵力涌动一次投骰、属性/专注共用、日志明细和新档读写保留；阿德里尔恶咒最多两种。缚灵者已选额外专长保留，绝境巡行者、镜像和瞬袭/加速叠加抽查。历史详细清单见 `测试指引-0.3.4历史.md`。
