CotW Wrath Prototype 0.14.34：五项狂暴之力

本轮从原迁移清单完成 Superstition、Ghost Rager、Witch Hunter、Disruptive、Spellbreaker 五项。它们是狂暴之力，子效果和私有资源不另计数；新增普通专长和新法术根均为0。0.14.33 的 Spiritual Guardian、Kinetic Invocation、Windsight、Cold Snap、Smoke Storm 已获用户游戏正常反馈，本轮保持其生产实现。Atavism 继续移除。

一、选择与规则

在野蛮人、Skald、Instinctual Warrior、原生 Primalist 的狂暴之力选择，以及 Extra Rage Power 中检查本批项目；启用当前 TabletopTweaks 的独立 Primalist 选择池时，也检查该池。普通 Bloodrager 不因此获得 Primalist 专属选择资格。所有项目仅在相应狂暴／激发狂暴效果期间生效，沿用游戏的分享机制和合格等级计算。效果成长按野蛮人、Skald 与 Primalist 血怒者等级合计；选择所需的6／8／12级必须由其中一个合格职业／变体单独达到。Skald 分享效果按施放者等级计算，不按接受者等级计算。

Superstition（迷信）：抵抗法术／类法术时获得 +2 表现加值，每4个来源合格等级再 +1（4级 +3、8级 +4、12级 +5、16级 +6、20级 +7）。对原 CotW 明确列出的无害友方法术，非本人施放者仍会引发豁免：例如 Mage Armor（法师护甲）进行意志豁免，Haste（加速术）进行强韧豁免，成功则阻止该次效果；Cure Light Wounds（治疗轻伤）等列举治疗法术进行意志豁免，成功时治疗量减半。法术原已进行的豁免不会再重复掷一次。额外无害豁免只针对清单内的法术；类法术、超自然能力、自身施法、敌方施法及清单外法术保留原有施放／豁免规则，其中类法术仍享有上述正常豁免加值。

Witch Hunter（猎巫者）：需要 Superstition。狂暴期间对具有职业施法能力或法术／类法术能力条目的生物造成额外伤害，来源合格等级1～3时为 +1，每4个合格等级再 +1；每次伤害结算只在首个伤害分量上增加一次。沿用原 CotW 的施法能力判定，不要求目标当日仍有可用法术位；单独的炼金提取物不满足条件。

Ghost Rager（幽魂狂暴者）：需要 Superstition，且任一合格职业／变体达到6级。狂暴时物理伤害正常影响虚体敌人，并获得接触 AC 士气加值：6级 +3、8级 +4、12级 +5、16级 +6、20级 +7。加值不能使接触 AC 超过完整 AC，不增加普通 AC；同类加值依游戏规则选优。

Disruptive（扰乱施法）：需要 Superstition，且任一合格职业／变体达到8级。狂暴期间临时获得游戏原生 Disruptive 效果，使用其原生范围、敌我和专注检定路径。已有的永久 Disruptive 在狂暴结束后仍保留，临时来源不重复叠加同一专长效果。

Spellbreaker（破法者）：需要本批 Disruptive 狂暴之力，且任一合格职业／变体达到12级。按原 CotW 实现与游戏原生 Counterstrike 机制，威胁范围内的敌人成功防御施法时触发借机攻击；仍须满足正常近战威胁、借机次数和免疫等限制。防御施法失败保持游戏原有处理。Disruptive 与 Spellbreaker 均登记为本批狂暴之力，不向普通专长池重复登记原生专长。

二、游戏回归步骤

1. 使用最终安装包替换当前 CotW，冷启动，打开 ModMenu 检查五项模块状态；再打开一次，确认没有新增重复条目或失败提示。
2. 新建角色、旧存档升级和洗点分别打开对应狂暴之力页。检查无 Superstition 时 Witch Hunter、Ghost Rager、Disruptive 不可选；任一合格职业／变体均不足6级时 Ghost Rager 不可选，不足8级时 Disruptive 不可选；没有本批 Disruptive 或各合格职业／变体均不足12级时 Spellbreaker 不可选。普通原生 Disruptive 不代替本批狂暴之力前置。检查 Skald、Instinctual Warrior、原生及启用的 TTT Primalist 列表、Extra Rage Power，并确认普通 Bloodrager 不误获资格。
3. 比较狂暴前、期间、结束后抵抗法术／类法术／超自然能力的豁免明细；再由队友分别施放 Mage Armor、Haste、Cure Light Wounds，观察意志／强韧／意志豁免以及失败生效、成功抵消／半治疗。治疗轻伤应走正常施法与接触交付；用带有既存治疗抗性或强效超魔的治疗对照最终治疗量。本人施放、类法术增益、清单外无豁免法术不得被误加这次无害豁免。
4. Witch Hunter 分别攻击真正施法者、只有类法术能力的敌人和普通无施法敌人，查看伤害明细；对照不同合格等级与狂暴结束后的结果。
5. Ghost Rager 使用普通物理武器攻击虚体目标，比较狂暴前后；让敌人使用接触攻击，检查加值成长与完整 AC 上限，并加入其他士气 AC 加值对照。重叠个人狂暴与不同等级 Skald 来源，结束最强来源后重新检查上限，普通 AC 不应增加。
6. Disruptive 让敌人在原生作用范围内外防御施法，检查专注明细；分别在已有／没有永久 Disruptive 时启停狂暴，结束后检查永久专长。再测试先进入狂暴、随后取得永久 Disruptive，以及两种临时狂暴来源先后结束；永久专长和剩余临时来源都应保留，最后一个纯临时来源结束后才撤销临时专长。
7. Spellbreaker 优先在回合制检查，并以即时制对照。在仍有借机次数、近战威胁成立时，令敌人成功防御施法；再检查失败、范围外、机会用尽和狂暴结束等反例。有原生 Counterstrike、Spell Combat 或 Spellstrike 的混合角色额外检查启停狂暴后原能力仍在。
8. Skald 与个人狂暴重叠、保存再读取、切换场景后，检查效果来源不翻倍、退出较强来源后恢复较弱来源；以高等级 Skald 分享给低等级接收者，对照 Superstition、Witch Hunter 和 Ghost Rager 的来源等级成长。拥有 Ferocious Beast, Greater 时检查恒定狂暴之力的伙伴共享。存读档后检查 Disruptive 临时／永久来源与 Counterstrike、Spell Combat、Spellstrike 原有能力的启停和保留。
9. 保留原有 ToyBox／DragonChanges／COP／Mystical Mayhem 组合冷启动，打开普通专长页与职业法术表，并抽查033五项和 Terrifying Howl，确认已通过功能保持。

三、验证证据

托管检查使用本机最新版游戏原生程序集和蓝图归档，执行实际 CanSelect／前置判断、事实管理器与组件启停、EventBus、Rulebook、治疗和伤害结算，以及真实 RegisterAll／RegisterOptional 调用方。选择池检查保留既有条目和顺序；单模块追加故障、可选池缺失／延迟出现、重复登记和模块菜单名称／状态均有正反例。完整构建与从最终安装 ZIP 提取 DLL 后的专项复跑分别执行，详细结果和文件 SHA256 写入同版本交付自检 TXT／JSON。

Superstition 检查保留原 CotW 的98条意志、36条强韧和20条治疗清单行，覆盖同一施法多目标、重叠来源、已有豁免不再追加、豁免成功／失败，以及治疗减半与已有减免相乘。触摸治疗经过原生充能、交付上下文、Cure 效果和实际 HP 变化。Witch Hunter 经过原生伤害订阅，覆盖职业施法、类法术、普通目标、炼金单独来源、等级成长和最强来源关闭后恢复较弱来源。

Ghost Rager 检查原生 AC 计算、多个来源和其他士气加值下的完整 AC 上限，以及原生虚体组件对物理／能量伤害的处理。Disruptive 检查真实专长添加与移除、永久来源先后取得、多临时来源、来源交接、原生范围效果动作与专注检定；仅对其固定原生专长采用一个专用授予钩子，不修改其他专长或原生蓝图。Spellbreaker 检查原生防御施法判定、MagusController 借机队列、接战处理、借机次数、攻击命令和次数消耗，并覆盖与原生 Magus 能力的来源共存。原生 Counterstrike 移除可能销毁整份 Magus 部件；专用后置处理只为仍生效的本批来源接回其自身借机标记，不恢复已经移除的外部能力。

上述托管环境构造角色、缓存、时间与骰点，控制场景几何和最终命令调度。Spellbreaker 的队列夹具使用即时制规则；回合制的场景调度与攻击表现应按第7步记录。组件 JSON 收据往返检查覆盖保存字段，不等同完整游戏存读档。真实游戏界面、动画、区域调度、组合模组启动和完整存读档结果按本说明的游戏步骤单独记录。

Harmony 编译引用继续固定2.0.4.0及已审核 SHA256；运行时 API 与执行兼容检查覆盖2.0.4和2.3.6，不替换游戏或 UMM 自带的 Harmony。
