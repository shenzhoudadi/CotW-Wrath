0.3.0：Improved Combat Expertise 实验测试

本次目的
本版在已移植的 Steadfast Personality 和 Extended Bane 之外，增加 Improved Combat Expertise。它沿用《正义之怒》的 Combat Expertise 能力和罚值计算：拥有本专长时，开启 Combat Expertise 所受的近战攻击与战技攻击罚值减少 2。游戏内新增文字在中文语言下也显示英文，不再自行汉化专长名称。
本说明原用于 0.3.0 首次验收。之后用户反馈新专长“正常生效”，并提供一张 BAB +9、寓守于攻攻击罚值 -1 的战斗日志截图；无新专长基准、战技、升级与读档仍未明确验证。请使用独立测试存档，并记录实际结果，没测到的项目填“未测”。

准备角色
建议使用普通战士，智力至少 13，基础攻击加值至少 +8，已经取得原生 Combat Expertise。避免同时拥有其他会改变 Combat Expertise 罚值的专长、神话能力或职业能力；若角色已有这些能力，请记录名称。
新专长正常先决条件为智力 13、基础攻击加值 +8、Combat Expertise。先在战士额外专长或普通专长界面检查它能否合法选取，不能只用百宝袋直接添加来证明先决条件正确。
本实验专长显示名：Improved Combat Expertise (CotW Prototype)
百宝袋搜索编号：c01055f33991416bb1ecc332a578e7cd
内部名：CotWWrathPrototypeImprovedCombatExpertise

核心对照：同一个角色、同一目标、同一攻击条件
1. 保存一份尚未取得 Improved Combat Expertise 的基准档。确认角色基础攻击加值为 +8，且 Combat Expertise 已取得。
2. 从基准档出发，关闭 Combat Expertise，向同一个敌人做一次普通近战攻击，记录战斗日志里的攻击修正明细。
3. 仍无新专长，开启 Combat Expertise，再攻击同一目标。基础攻击加值 +8 时，原生罚值通常是 -3；以实际日志为准，记作 P。
4. 读回基准档，通过正常升级选取新专长，或使用百宝袋 Search 'n Pick → Features 添加上述编号。重新关闭再开启 Combat Expertise，以便重新计算状态，然后在相同条件下攻击同一目标。
5. 预期 Combat Expertise 的罚值比 P 少 2；若原先是 -3，应变成 -1。攻击骰本身可以不同，只比较日志明细中的修正值。新专长不应更改 Combat Expertise 提供的防御加值。
6. 关闭 Combat Expertise 再攻击，预期新专长不额外增加普通攻击。若角色能稳定触发绊摔等战技，也可比较开启状态下战技攻击修正是否同样改善 2。

边界与回归
- 智力低于 13、基础攻击加值低于 +8，或没有 Combat Expertise 的角色，不应能在正常升级界面合法选取。百宝袋强行添加会绕过先决条件，不能用于这一项。
- 重复打开角色专长页面或反复读取存档，不应让罚值持续下降。正常专长只能取得一次。
- 另存并完全退出重进后，再测一次开启 Combat Expertise 的攻击修正。若需要测试移除，在独立分支用百宝袋 Remove 新专长，重新切换 Combat Expertise，罚值应回到基准。
- 确认旧存档中的 Steadfast Personality、Extended Bane 仍在，且没有重复；若此前有可靠的测试档，可做一次简单效果回归。0.2.0 的笼统“生效”反馈不能替代这次升级读档检查。
- 中文游戏语言下应显示英文专长名和说明；不要出现空白或 unknown key。
