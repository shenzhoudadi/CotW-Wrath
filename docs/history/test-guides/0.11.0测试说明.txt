CotW 0.11.0（内含 Medium 0.4.3）测试说明

本批：Phrenic Amplification集中菜单，以及Burst of Force、Telekinetic Storm。共29道本包法术，两种完整流派仍Ferocity/Faith。0.10.1与此前功能按用户“一切正常”验收；用户随后再次确认上一包新增法术正常。本包新内容尚待游戏验收。

完全退出游戏后覆盖原生CotW安装目录。内含Medium，不同时启用旧独立UMM Medium。旧GUID与英文内容保留。首次打开旧档时，原有Psychic施法与增幅特征通过原生AddFacts补上菜单入口；不需要重新学习增幅。原来拖入快捷栏的增幅按钮仍可用，也可以自行换成总入口。

一、Phrenic Pool菜单（重点）
展开能力栏，应看到一个Phrenic Pool入口，图标角标显示当前剩余灵能点。
Phrenic Pool → Defensive Prognostication → 1 point / 2 points。
Phrenic Pool → Overpowering Mind → 2 / 4 / 6 points（后两档仍分别要求Psychic 8级/15级）。
其他已学会的即时开关直接在总入口下。Psychofeedback也放在总入口下，列出已知法术可牺牲的环级与三种属性；保留从法术本身展开转换的旧路径。
游戏原版展开窗会关闭其他展开窗，因此本包逐级替换同一个面板。进入档位页后点击Back to Phrenic Pool回总菜单；再次点击总入口或箭头关闭。不是同时堆叠三个浮窗。

请优先核验：
1. 新建与已有Psychic人物仅显示已学会的增幅；未学会或未到等级的档位不出现。旧档读入后能看到入口，升级/洗点后列表更新。
2. 点菜单和返回不扣动作、不扣灵能、不加状态；选择另一个模式立即关闭前一个，主动关闭立即去掉模式状态。已付费产生的防御等效果继续正常存在。
3. 施法扣点、失败退点、休息恢复后，顶层角标随剩余数量变化；点数为0也能打开菜单与关闭原有模式。即时制和回合制各检查一次。
4. 原来的快捷栏按钮继续有效；总入口和单个叶子按钮可按原版方式拖入快捷栏。其他职业的普通开关/法术菜单不变。
5. Psychofeedback从新菜单使用时，实际扣2灵能和对应环级1个法术位，持续每Psychic等级1分钟；不执行被牺牲法术的原效果。缺点或缺法术位时仍由原生转换规则阻止。
6. 保存重读后入口、学会的档位和快捷栏仍正确。菜单展开位置、返回与图标数值需要真实游戏界面确认，独立检查没有渲染Unity画面。

二、Burst of Force（Psychic / Wizard五环）
自身周围20尺，排除施法者但会打到友军。每CL 1d6力场伤害，上限15d6。强韧成功伤害减半，且不再进行击倒判定；强韧失败才进行反射，反射也失败时倒地。允许法术抗力。
建议测强韧成功、强韧失败/反射成功、两次都失败三种分支，以及20尺外目标、友军与施法者自身。Intensified将上限提高至20d6；Empower/Maximize和已验证的Focused Force可一起复测。Selective用于避免友伤。

三、Telekinetic Storm（Psychic九环）
自身周围40尺，只影响敌方，排除施法者/友军。每CL 1d6力场伤害，上限20d6；强韧成功减半且免除状态，失败则失神(Dazed)和震慑(Stunned)各1轮。允许法术抗力。Intensified提高上限至25d6。
沿用原CotW游戏适配：自动排除友方，没有新增逐个勾选豁免目标的界面。失神来源是力场，不额外带心灵影响；震慑/失神自身免疫仍适用。检查到期状态及时消失，无需存读档。

两道法术都请检查升级学习后保留、存读档、图标/时长/豁免栏、施法特效、法术抗力及伤害日志。使用原CotW所选原版图标和本机存在的特效。七提供者最新源码未查到同名实现，其他已完成法术继续可选联动，无新强制依赖。

独立检查包含原生托管菜单/转换数据、余量、原按钮身份、即时互换、法术学习/UI取数/PostLoad、超魔上限和预设豁免分支，以及整包兼容回归。不包含真实场景范围筛选、渲染、战斗随机检定、完整保存序列化；不是游戏实测。
未增加卷轴/商店、其余四流派或Occultist/Spiritualist职业主体。当前资料足够，无需另找规则资料。问题请带具体入口/法术、等级、模式、步骤与同次CotW日志/Player.log。
