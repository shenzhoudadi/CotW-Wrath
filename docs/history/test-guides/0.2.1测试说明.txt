0.2.1：英文文案与延长灾厄测试

本次目的
上一版坚定人格已由测试者确认实际豁免效果生效。本次新增“延长灾厄”，验证需要读取属性和管理可用次数的机制，为后续能力与职业移植打基础。两个专长现在分别注册，单项依赖失败不会阻止另一项注册。
这仍是两个专长的实验包，没有新增职业。测试者反馈 0.2.0 “生效”，但没有给出各项测试细节；0.2.1 只改显示文字，尚未经过游戏内复验。为了避免译名与社区习惯冲突，游戏内专长名和说明在中文语言下也显示英文；此前提到的模组界面并不存在，注册结果请查看游戏日志。

升级前
完全退出游戏，备份旧模组目录、启用配置和升级前的测试存档。按 README.zh-CN.md 替换同一个 CallOfTheWildWrathPrototype 目录；不要同时启用两个版本。
保留 0.1.1 ZIP 和升级前存档。以后若要回退，需要同时恢复旧包和旧档；0.1.1 不包含延长灾厄，不能用它验收已经选了新专长的存档。

先做旧功能回归
1. 启动 0.2.1，查看游戏日志是否分别记录 Registered: Steadfast Personality、Registered: Extended Bane；专长名和说明在中文语言下也应是英文，不应出现空白或未知键。
2. 读取已有坚定人格的测试档副本，检查专长与文本是否仍在、没有重复。
3. 按《百宝袋快速测试.txt》再用七彩喷射对照一次，预期效果仍与 0.1.1 相同。
4. 保存到新槽，完全退出重进，再查专长和实际豁免。
此前只确认了实际豁免生效，这几项不能直接沿用旧反馈而跳过。

快速准备延长灾厄的测试角色
建议新测试档中的普通审判官，使用原生基础职业，先做到 7 级；应已获得灾厄能力，且能在正常升级中选择普通专长。其他职业/变体的复杂灾厄来源以后再测。
可用百宝袋补经验并正常完成升级、改感知；不要直接改灾厄资源剩余值或资源上限，也不要打开无限资源/消耗不减。
首测角色面板：感知 14，感知调整值 +2；没有额外灾厄、其他增加灾厄次数的能力或装备。
先不要选延长灾厄，休息恢复资源，保存为“7级审判官无新专长”基准档。

本专长信息
显示名称：Extended Bane (CotW Prototype)
百宝袋搜索编号：f362a8fdff7146d5b2e614c39349718d
内部名：CotWWrathPrototypeExtendedBane
先决条件：已有审判官灾厄能力。
规则：每日灾厄轮数上限增加正感知调整值。感知 +2 就多 2 轮；感知为零或负数时不减少资源。只能选一次。
注意区别原生“额外灾厄 / Extra Bane”：那是固定增加 3 轮，是另一个专长。不要搜错，也不要把两者的增加量混为一谈。

核心测试一：选择与先决条件
在正常普通专长选择界面测试：已有灾厄的审判官应能选；没有灾厄的角色不能合法选；已选后不能再选第二次。记录是否隐藏、不可选及提示文字。
用百宝袋直接 Add 可以快速测试效果，但会绕过正常选取，不能用来证明先决条件通过。

核心测试二：休息后的总轮数
1. 无延长灾厄，7 级普通审判官休息后，基础应为 7 轮。若不是 7，先排查其他加值，并记录真实基准 N。
2. 从同一个基准档开始，只添加或合法选取延长灾厄，休息。
3. 感知 14（+2）时，应比同条件无专长多 2 轮：7 → 9，或 N → N+2。
4. 实际战斗中开启灾厄，观察轮数正常消耗；关闭后不应继续因本专长额外扣减。攻击、伤害加值仍是原生灾厄的效果，本专长只改每日可用轮数。
可在回合制中记录经过的回合与剩余量。不要只看开启开关是否亮了就判定资源测试通过。

核心测试三：感知装备与当前剩余量
1. 在感知 14、已选专长的角色上，穿戴能让最终感知变为 18（+4）的装备，例如有效的感知 +4 头带。以角色面板最终数值为准。
2. 休息后应为 7+4=11 轮；脱下恢复感知 14，再休息应为 9 轮。
3. 消耗一些灾厄轮数后，再穿脱感知装备。本专长不应因为这个动作免费回满。
游戏把“当前剩余量”和“最大值”分开保存，界面可能只显示前者。加/移除专长或降低感知后，旧剩余量也可能暂时高于新上限；这是沿用原生资源处理，不是此组件即时削减。请分别记下动作前后的剩余量，并在休息后比较上限。

核心测试四：零和负感知
每组都在新的测试分支上改属性，并分别做有无本专长、休息后的对照：
感知 10（+0）：不多也不少，仍为基准 N。
感知 8（-1）：不扣减基础轮数，仍为基准 N。
感知低可能影响审判官法术施放，这不是本专长改变的规则；本项只检查已取得的灾厄资源。

核心测试五：额外加值与重复刷新
可补做原生额外灾厄（固定 +3）共存：审判官7、感知14时，原生额外灾厄加本专长，休息后应为 7+3+2=12 轮。
多次打开角色界面、切换队友或重复加载，不应让上限不断上涨。重复查询不会再次累加同一专长。

核心测试六：保存、重载、移除与洗点
1. 带着本专长另存，完全退出重进；专长和资源保持，休息后的轮数仍正确，没有翻倍。
2. 快速检查可在独立分支用百宝袋 Remove 本专长，然后休息；回到无此专长的基准。此动作不等于正常洗点验收。
3. 再做一次游戏内正常洗点，重建为相同职业等级和属性、但不选延长灾厄，休息后回到基准；注意洗点不要顺便改变了原生额外灾厄或其他资源加值。
4. 取消一轮尚未确认的正常升级，不应留下新专长或资源加值。
