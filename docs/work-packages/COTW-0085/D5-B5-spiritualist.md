# Spiritualist · D5 复查与 B5 修复

复查基线为 `fbc576f`，对应 [C 生命周期合同](C-spiritualist-contract.md) 和 [D4 修复记录](D4-B4-spiritualist.md)。

- **启动与升级隔离（C01/C03）**。Wrath 的静态 `AddClassLevels.LevelUp` 带第四个可选 `UnitFact` 参数。旧技能同步补丁用三参数签名，候选 DLL 能注册蓝图但常规核心补丁安装会抛错。已改成真实签名。在原生 `AddPet.TryLevelUpPet` 中仅跳过有效私有 Phantom 选项的主人蓝图进度覆盖，继续由幻影自己的 `AddClassLevels` 升级。Dog 对照走原生覆盖。
- **伙伴的存档引用（C09/C17）**。原生 `TryUpdatePet` 将未解析的存档引用和从未创建的伙伴都读成空实体。0085 专用入口保留原生挂载等待；有存档 ID 时等引用能解析。更新和撤销入口遇到不匹配的伙伴蓝图、其他主人或预览关系时拒绝接管，并保护外部实体。普通宠物继续走原生方法。
- **召回（C04/C05）**。沿用原生 FreePlaceSelector 选点，核对三维位置、可行走地面及主人所在导航区域。只有实际发生移动才扣次。同一主人落点和幻影位置的重复召回不扣次，区域卸载或旧伙伴移除后清掉本次区域的记录。
- **Skill Focus（C11）**。重训撤销核对实际赠予的原生事实引用及职业来源，保护后来由其他来源授予的同名专长。以蓝图 GUID 记录的旧测试存档仅在原生来源明确为 Spiritualist 时迁移。
