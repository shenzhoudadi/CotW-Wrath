# Spiritualist · D10 原生伙伴绑定与授权时机

复查基线为 `6045c99`，对应 [C02、C03、C09、C17](C-spiritualist-cases.json)。[D9/B9](D9-B9-spiritualist.md)

- **初次绑定**。真实的原生事实 Activate 会运行 `AddPet.OnActivate`，再进入 TurnOn。同轮观察到原生已调用 `SetMaster`，但是情绪 Link 在旧 Activate 回调内检查 `IsTurnedOn`，第一次没有记录伙伴。后续动作再次查找才补记。现改用原生组件 TurnOn 接点，初次绑定可立即记录。Shared/Fused 与受绑定的幻影特性也用同一原生授权时机，存档修复入口只刷新已开启的授予。
- **原生调用与隔离**。在管理宿主预先注入两个 Anger 实体和一只 Dog 的原生记录。实走事实激活、`IUpdatePet.TryUpdatePet`、`SetMaster`、`UnitPartPetMaster.AddPet`、事实 Reapply 及 `RemoveMaster`。错误跨主人引用不改动任何原生伙伴表，清退后重放不重绑旧实体，Dog 仍归原主人。
- **等级请求**。在 `AddClassLevels.LevelUp` 入口记录原生请求。两只幻影各请求自己的一级，已在 1 级的幻影重放时无请求，主人 Spiritualist 2 级时对同一实体请求补 1 级，另取四级异职时无请求，Spiritualist 20 级时对同一实体请求余下 18 级。夹具预置当前等级，在实际等级提交之前截住请求。
