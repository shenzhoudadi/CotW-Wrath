# Spiritualist · D6 情绪法术复查与 B6 修复

复查基线为 `17c0a15`。按 [C16](C-spiritualist-cases.json) 核对主人情绪能力及原生资源。前轮伙伴与补丁启动修复见 [D5/B5](D5-B5-spiritualist.md)。

- **每日次数**。原作资源挂载只在首次授予时填入次数，Wrath 的 `RestoreOnLevelUp` 会在角色重算升级特性时补满次数。0085 的主人和 Phantom 共用原生资源挂载，保留首次发放和原生休息恢复，升级重算不补满。24 个主人次数池分别在 5/7/9/16 级开始，解锁后每四个 Spiritualist 等级增加一次。
- **施法参数**。每个可执行选项只接一份原生职业参数及所属能力的单次消耗。主人用 Spiritualist 等级与 Wisdom，Phantom 用自己的职业等级及对应属性。转换清空材料要求，保留类法术原法术派系。按照原作，Furious Wail 与 Despairing Shout 的超自然版本绕过法术抗性并清除超魔。
- **持触释放**。Wrath 的 `UnitPartTouch` 将起手施法参数传给原有触碰蓝图，离战原生先移除持触，最后尝试返还法术书自发法术位。仅对 0085 的情绪类法术跳过最后一步。Vampiric Touch 和 Freedom of Movement 保留原有原生触碰 GUID，普通法术的持触清理和返还路径继续调用原生。
- **已有提供方**。对照 ExpandedContent 和 TabletopTweaks 的 Inflict Pain。两项同名法术的减值类型与战技检定覆盖有差异，保留已审计的 ExpandedContent 根。私人法表的 98 个可直接按原 GUID 比对的原生条目环位一致，当前解析的原生行在同环无重复。
