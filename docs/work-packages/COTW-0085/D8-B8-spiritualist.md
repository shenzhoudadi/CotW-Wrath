- **原生恢复入口**。Wrath 在生命状态改变后发布 `IUnitLifeStateChanged`，`UnitDescriptor.Resurrect` 会在清理死亡状态后调用 `ForceUnitConscious`。先前只有休息复活枚举器处理幻影自身的隐藏状态。主情绪现在在死亡转为存活后重新验证原生主人、主情绪和 AddPet 授权，对同一个伙伴清除收回意图。可在本地显示时调用原生 `UnitPartPet.SetHidden(false)`，其他时候保留待显现。实际 HP、位置和复活仍由原生流程处理。
- **休息及重放**。原生正常休息组会跳过 `ShouldBeHidden` 的宠物，保留仅从本次休息主人补充有原生 `ResurrectOnRest` 标记的同源幻影。原生休息循环也可直接写 Conscious，只有仍需处理可见性时才重新验证伙伴并调用同一个恢复入口。正常显现确认原生已经显示伙伴后提交新状态。
- **阵营和派系**。原生 `SetMaster` 已复制主人的派系并更新单位组。保留原生派系绑定。九宫格阵营的初次、区域及变更事件现共用一个同步方法，写入复用 `UnitAlignment.Set`。重训沿用原生提交和事实关闭入口。
