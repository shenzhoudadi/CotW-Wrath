## 原生学习和复用复查

- Wrath 的 `SelectSpell` 在每份法表内从索引 0 开始，不能用它索引全部历史法器。本轮通过私有法书标记把唯一的来源法表绑定到稳定法器槽键、学派或 Panoply 和 Extra Spells 身份。原生 `SelectSpell` 的既有字段携带来源法表。法表均直接引用原有法术根。
- `ApplySpellbook` 继续负责法书进展。`LevelUpState.OnApplyAction` 为当前可学的法器配额建立原生 `SpellSelectionData`。原生使用 `GetSpells` 的 DLC 过滤结果，私有规则再核对来源、法术环位、实时智力和本书已有法术。候选耗尽时不留空页面，配额保存在账本里。
- 候选变化替换整份来源选择数据，以原生页面更新方法重建。复用已有 Bard Masterpiece 的选择项过滤接点，保留本次已选的根，继续由原生动作匹配法书、法表、槽和环位。既有原生或其他职业法书选择不经 0099 来源校验。
- D 在中途指出原始法术引用绕过 DLC 过滤、候选变化后原生页面可能复用旧集合、旧重放负例会被已知法术判定提前拒绝。修复后用实际 `DlcCondition` 和原生 `GetSpells` 验证隐藏根不占槽、旧 Apply 不学习。预览重放改从未学习的副本开始。正例正常学习且不改本体，负例确认旧来源删除时，同一未知根仍能由另一来源选择，旧动作不能学习或扣槽。原生 `TryUpdateSamePhase` 确认候选变化且槽数相同也拒绝复用旧页。
